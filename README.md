# Intelligent Contract Analysis Agent

## Problem
Legal teams spend significant time reviewing contracts manually and often miss critical risks.

## Solution
This agent analyzes contracts, extracts clauses, identifies risks, and suggests improvements.

## Features
- Clause extraction
- Risk detection
- Compliance validation
- Negotiation insights

## Microsoft IQ Integration
This solution uses Foundry IQ by grounding contract analysis using a clause library and contract standards knowledge base.

## Tech Stack
- Microsoft Copilot Studio
- Foundry IQ (Knowledge Layer)

## Impact
- Reduce review time by 70%
- Improve accuracy
- Speed up negotiations
