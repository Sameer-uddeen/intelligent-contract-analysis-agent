# Demo Video Script
## Opening
Hello, I built Intelligent Contract Analysis Agent for the Enterprise Agents track.

Legal teams often spend significant time reviewing contracts manually. This project helps by automating first-pass contract review using Microsoft Copilot Studio and Foundry IQ.

## Problem
The problem is that contract review can be repetitive, slow, and inconsistent when large volumes of agreements must be checked quickly.

## Solution
This agent analyzes contract documents, extracts key clauses, identifies risks, validates against a contract standards knowledge base, and suggests negotiation improvements.

## Show the Setup
Here is the Copilot Studio agent.
The knowledge base includes a contract rules file.
I also uploaded a sample contract PDF.

## Demo the Analysis
Now I ask the agent: Analyze the uploaded contract and identify risks, compliance issues, and negotiation suggestions.

The agent returns:
- A summary
- Extracted clauses
- Risks
- Compliance issues
- Risk score
- Negotiation suggestions

## Show Comparison
Now I repeat the same analysis using a lower-risk contract.
This shows how the same agent can distinguish between high-risk and low-risk agreements.

## IQ Layer Statement
This solution integrates Foundry IQ by grounding contract analysis in a contract standards knowledge base.

## Close
This project demonstrates how Microsoft 365 Copilot and Copilot Studio can help legal teams review contracts more consistently and efficiently.
